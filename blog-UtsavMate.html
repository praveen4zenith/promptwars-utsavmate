1. The Problem: The Chaos of Indian Celebration Planning

Indian celebrations—weddings, milestone birthdays (like 1st Annaprashan ceremonies), and community festivals—are grand, emotionally resonant, and notoriously intricate. Unlike Western single-reception events, an Indian wedding or festival spans multiple days, complex rituals (Baraat, Milni, Varmala, Vedic Pheras, Sangeet), hundreds to thousands of attendees, and delicate dietary needs (Pure Vegetarian, Jain counters, live Chaat stations).

Core Planning Frustrations:
  • Unpredictable Budget Creep: Host families start with a budget (e.g., ₹25 Lakhs) but quickly experience 40–60% budget overruns due to lack of category breakdown boundaries.
  • Generic AI Tools Fail at Cultural Nuances: Generic chatbots don't know the difference between Muhurtham and Sangeet, suggest imported flowers that wither in Indian heat, or propose rigid timelines that ignore auspicious Hindu ritual timings.
  • LLM "Hallucinated Math": Asking an LLM to balance budgets often produces incorrect category sums that do not equal the requested total, or invalid balances.
  • Vendor Contract Traps: Hidden charges like generator backup fuel, corkage fees, and outdoor sound cutoffs (10:00 PM Supreme Court residential curfew) catch hosts completely off-guard.

UtsavMate AI was engineered to solve this by combining the creative cultural depth of generative AI with the strict numerical accuracy of deterministic TypeScript software.

Architectural Pillars

  • Client-Side Resilience: User input state, category slider adjustments, and customized task checklists are continuously persisted in browser localStorage. Users never lose their work on browser reload.
  • Zero Server-Side State: No heavy external database or authentication layers are needed. Plans can be downloaded or uploaded as portable JSON files.
  • Secure Edge API: Next.js Route Handlers act as a secure proxy to Google Gemini API. API keys and model configurations remain exclusively on the server.

3. AI Integration: Structured Gemini Prompts with Fallback

UtsavMate AI integrates with Google Gemini (Gemini 2.5 Flash) to generate culturally rich concepts, hour-by-hour schedules, vendor questions, and contingency recommendations.

Strict JSON Schema Enforcement

To prevent freeform conversational output from breaking the UI, the prompt enforces strict JSON output mode with explicit schema definitions: 

const response = await fetch(endpoint, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    contents: [{ parts: [{ text: prompt }] }],
    generationConfig: {
      temperature: 0.7,
      responseMimeType: "application/json"
    }
  })
});
Dedicated Host / Celebrant Separation:
To support creative concepts (e.g., Event Title: "Explore Roblox World") without losing the celebrant's identity, the schema accepts a separate hostName field (e.g., "Kabir"). The AI customizes rituals, birthday cake-cutting, or baraat moments around the specific individual, rather than relying on placeholder names.

The Resilient Offline Fallback Engine

A major engineering requirement was zero downtime. If GEMINI_API_KEY is missing, or if the API returns 429 rate limits, UtsavMate AI automatically switches to its Offline Intelligence Fallback Engine. It synthesizes fully populated, realistic plans in milliseconds using curated Indian cultural event templates, dynamically substituting the user's city, guest count, budget, and celebrant name.

4. Deterministic Budget Logic: Why We Never Trust AI Math

A key principle of UtsavMate AI is: Generative AI is great at cultural synthesis, but terrible at deterministic financial math.

If an LLM allocates ₹10,00,000 across 7 categories, it often hallucinates sums that add up to ₹9,40,000 or ₹10,80,000, rounding unpredictably and destroying user trust.

The Cardinal Rule: Budget arithmetic is 100% deterministic, executed in pure TypeScript within src/lib/budgetEngine.ts.

Deterministic Arithmetic Workflow:

  1. Sanitization & Bounds Checking: All user inputs pass through sanitizeCurrencyInput(). Negative values, NaN, floating decimals, and invalid string inputs are clamped and rounded to whole Indian Rupees (₹).
  2. Guaranteed Sum Reconciliation: When generating recommended splits (e.g., 30% Venue, 26% Catering, 16% Decor, etc.), the engine computes integers and assigns the exact remainder to the final category: 
    // Exact sum matching guarantee
BUDGET_CATEGORIES.forEach((cat, index) => {
  if (index === BUDGET_CATEGORIES.length - 1) {
    result[cat.key] = Math.max(0, safeBudget - allocatedSum);
  } else {
    const pct = cat.recommendedPercent[eventType] ?? 10;
    const amount = Math.round((safeBudget * pct) / 100);
    result[cat.key] = amount;
    allocatedSum += amount;
  }
});
  3. Live Overrun & Surplus Detection: As the user drags sliders or inputs custom amounts, calculateBudgetMetrics() computes remaining balances, flags deficits, and calculates percentages instantaneously with zero network latency.
  4. Indian Currency Formatter: Custom regex formatting delivers authentic Indian numbering comma separation: formatINR(1500000) ➔ ₹15,00,000 and formatINRShort(1500000) ➔ ₹15 Lakh.

5. Architectural Trade-offs & Design Decisions

Every engineering decision involves pragmatic trade-offs. Here is the rationale behind our key choices:

Choice What We Chose Alternative Considered Rationale & Trade-off
Framework Next.js 14 App Router Vite SPA + Express Backend Unified deployment on Vercel with zero-configuration serverless API endpoints and integrated SEO.
Data Storage Browser localStorage + JSON export/import PostgreSQL / Supabase Auth Immediate accessibility without login friction, passwords, or cloud database latency. Trade-off: Plan data stays on user's device unless exported.
Math Execution Pure TypeScript Engine LLM-generated calculations Mathematical precision, 100% test coverage with Vitest, and instant recalculation on slider drag.
AI Resilience Server Route Proxy + Dynamic Fallback Direct Client SDK calls Guarantees API key security, prevents CORS issues, and provides an offline fallback when API limits occur.
Export Format CSS @media print Brief Heavy client-side PDF libraries (jsPDF) Zero bundle size overhead, crisp vector printing on both A4 and mobile devices, and native browser PDF saving.

6. Summary & Takeaways

UtsavMate AI demonstrates how modern full-stack web engineering should interface with Large Language Models:

  • Use the LLM where it excels: cultural storytelling, rich thematic recommendations, and creative schedule sequencing.
  • Use deterministic code where accuracy is paramount: currency math, budget allocation rules, input validation, and boundary conditions.
  • Keep credentials safe on the server and provide seamless offline fallback modes so the user never experiences an error screen.
